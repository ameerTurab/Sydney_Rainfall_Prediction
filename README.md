# Project Objectives

This project aims to:

- Predict rainfall occurrence using historical weather observations from Sydney, Australia.
- Compare the performance of a Dense Neural Network and a Long Short-Term Memory (LSTM) model.
- Perform data cleaning, preprocessing, and feature engineering.
- Develop an end-to-end deep learning workflow for rainfall prediction.
- Evaluate and compare the predictive performance of both models.

---

# Project Description

Rainfall prediction is an important problem in environmental science, hydrology, and climate studies. Accurate prediction can support flood forecasting, water resource management, and agricultural planning.

This project investigates rainfall prediction using historical meteorological observations collected in Sydney, Australia. Two deep learning approaches are implemented and compared:

- Dense Neural Network (Binary Classification)
- Long Short-Term Memory (LSTM) Network for Time-Series Forecasting

The notebook demonstrates a complete machine learning workflow, including:

- Data preprocessing
- Missing value analysis
- Data cleaning
- Feature engineering
- Model development
- Model training
- Performance evaluation

# Results

The Dense Neural Network achieved better classification performance than the LSTM model.

The LSTM successfully captured temporal dependencies within the weather data; however, forecasting future rainfall remains a more complex task due to the inherent variability of meteorological processes.
